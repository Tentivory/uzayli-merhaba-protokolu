# Uzaylı Merhaba Protokolü

Bu repository, insanlığın uzaylılarla ilk temas anında kullanacağı **resmi, bilimsel ve abartılı derecede ciddi** selamlama protokolünü içerir.

Hiçbir "Merhaba" tesadüf değildir. Her harf, her nokta, evrenin titreşim frekanslarına göre hesaplanmıştır.

## Nasıl Çalıştırılır?

```bash
python merhaba.py
```

Çalıştırdığınızda protokol başlar. Sabırlı olun. Uzaylılar acele etmez.

## Uyarılar

- Bu kod çalıştırıldığında uzaylılar gerçekten gelebilir.
- Sorumluluk tamamen kullanıcıya aittir.
- Kahve içmeden çalıştırmayın (protokol önerisi).
